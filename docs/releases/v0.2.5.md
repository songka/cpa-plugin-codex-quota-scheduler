# Codex Quota Reserve v0.2.5

## Fixes

- Combine per-account scheduling notifications and usage reports into one message when the provider payload limit allows; paginate only between complete account sections.
- Include the reason an account stopped participating in Markdown and HTML notifications.
- Debounce temporary cooldown transitions for 30 seconds to avoid alerts for brief model cooldown flicker; sustained stops and confirmed recovery still notify.
- Hide cached accounts absent from the authoritative CPA active roster from the current plugin account view and notifications.

## Compatibility

- Requires CLIProxyAPI v8.0.27.
- The existing public repository and `registry.json` URL remain unchanged.
- Refresh the CPA plugin store after publication; CPA may cache the latest release for up to one hour.
