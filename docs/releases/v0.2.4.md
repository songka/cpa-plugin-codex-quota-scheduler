# Codex Quota Reserve v0.2.4

## Fixes

- Hide disabled, unavailable, and excluded models from the retry-chain model catalog.
- Support wildcard model exclusions and both global OAuth and per-auth-file exclusion settings.
- Keep a model visible when at least one account or provider still supports it.

## Compatibility

- Requires CLIProxyAPI v8.0.27.
- The existing public repository and `registry.json` URL remain unchanged.
- Refresh the CPA plugin store after publication; CPA may cache the latest release for up to one hour.
