# Codex Quota Reserve v0.2.3

## Fixes

- Shared model capacity and upstream overload failures no longer create an account-level cooldown.
- Nested retry attempts skip the failed account for the current request, while leaving it eligible for the next request after shared capacity recovers.
- Real 429 rate limits remain attributed to the account and continue to use the short cooldown path.

## Compatibility

- Requires CLIProxyAPI v8.0.27.
- The existing public repository and `registry.json` URL remain unchanged.
- Refresh the CPA plugin store after publication; CPA may cache the latest release for up to one hour.
